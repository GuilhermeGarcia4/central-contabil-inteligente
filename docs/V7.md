# V7 — providers de IA

A V7 preserva RAG, fontes, calculadoras e ferramentas financeiras no backend. Gemini é usado temporariamente em desenvolvimento para testes; OpenAI continua disponível sem mudança de frontend.

## Gemini

```dotenv
AI_PROVIDER=gemini
GEMINI_API_KEY=sua-chave-local
GEMINI_MODEL=gemini-3.7-flash
GEMINI_EMBEDDING_MODEL=gemini-embedding-2
```

## OpenAI

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=sua-chave-local
OPENAI_MODEL=gpt-4.1-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
```

Reinicie o backend depois da troca. Consulte `GET /api/v1/assistant/status` para confirmar provider, modelo, chat e embeddings. Chaves ficam no `.env` ignorado pelo Git ou em User Secrets; nunca no Angular.

No free tier do Gemini, use somente dados fictícios. Essa orientação não bloqueia produção em código: a configuração de produção deve ser definida separadamente pelo ambiente de implantação.

Em timeout, erro HTTP, JSON inválido ou chave ausente, o assistente retorna à resposta local fundamentada. Pesquisa tradicional, calculadoras e controle financeiro continuam independentes do LLM.
